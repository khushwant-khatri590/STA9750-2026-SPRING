# STA9750 Analytics Portfolio

## Overview

This repository showcases a collection of data analytics, statistical modeling, and data visualization projects completed as part of STA9750 at Baruch College. The portfolio demonstrates the application of analytical techniques to real-world datasets, emphasizing data-driven decision-making, exploratory analysis, statistical inference, and effective communication of insights.

The projects are presented through interactive HTML reports and web-based deliverables developed using modern analytical and reporting tools.

## Portfolio Contents

### Mini Project 01 – Public Transportation Financial Analysis

Analyzed financial and operational characteristics of major U.S. public transit systems to identify patterns in funding, expenses, and service performance.

### Mini Project 02 – Data Exploration and Visualization

Conducted exploratory data analysis and developed visualizations to uncover trends, relationships, and key insights within complex datasets.

### Mini Project 03 – Statistical Analysis and Insight Generation

Applied statistical methods and analytical techniques to investigate real-world questions and communicate findings through data storytelling.

### Mini Project 04 – Monte Carlo Simulation and Financial Modeling

Utilized simulation techniques to evaluate uncertainty and model long-term financial outcomes under varying assumptions.

### Individual Analytical Report

Completed an independent analytical study involving data preparation, statistical analysis, visualization, and interpretation of results to support evidence-based conclusions.
