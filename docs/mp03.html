Introduction

In this mini-project, I explore patterns of internal migration within the United States, with a focus on California. Using data from the American Community Survey (ACS) — the premier national survey conducted by the US Census Bureau — I analyze how people move between states and metropolitan areas, and what those movements mean for congressional representation.

The ACS collects data continuously, providing an up-to-date picture of the American public. For this project, I use two types of ACS data: state-level ACS-1 migration flows (based on one-year samples) to track movement between all 50 states, and metro-level ACS-5 flows (based on five-year samples) to understand which cities are most connected to California’s largest metro area, Los Angeles.

This analysis practices key data skills including downloading and parsing Excel and JSON files directly from government sources, combining multiple data sets using joins, computing summary statistics across groups, and building publication-quality visualizations. The ultimate goal is to forecast California’s population in 2030, estimate its congressional apportionment after the next census, and propose a data-driven advertising strategy to help California grow its political representation in Congress.

    message("Download complete.")
  } else {
    message("Using cached 2024 file.")
  }

  # 2024 file is already in long format
  # Col1 = current state, Col2 = prior state, Col3 = estimate
  raw <- read_excel(
    dest_file,
    sheet     = "Table",
    skip      = 0,
    col_names = FALSE
  )

  # Rename columns
  colnames(raw) <- c("state_current", "state_1y", "population", "moe")

  state_names_50 <- state.name

  # Cross-state flows (exclude "X" which means same state, exclude DC)
  flows_table <- raw |>
    filter(
      state_current %in% state_names_50,
      state_1y      %in% state_names_50,
      state_current != state_1y,
      population    != "X"
    ) |>
    mutate(
      population = replace(population, population == "N", "0"),
      population = suppressWarnings(as.integer(population))
    ) |>
    filter(!is.na(population)) |>
    select(state_current, state_1y, population)

  # Stayed in state rows (where state_current == state_1y, marked "X")
  # Get these from Supplemental sheet instead
  raw_supp <- read_excel(
    dest_file,
    sheet     = "Supplemental - Current Res",
    skip      = 0,
    col_names = FALSE
  )

  # Check structure
  colnames(raw_supp) <- paste0("col", 1:ncol(raw_supp))

  flows_stayed <- raw_supp |>
    filter(col1 %in% state_names_50) |>
    mutate(

  bind_rows(flows_table, flows_stayed) |>
    mutate(
      year_current = 2024L,
      year_1y      = 2023L
    ) |>
    select(state_current, state_1y, population, year_current, year_1y)

move_row_to_colnames <- function(X, row = 1){
  X    <- as_tibble(X)
  Xrow <- X[row, ]
  X    <- X[-row, ]
  colnames(X) <- unlist(Xrow)
  readr::type_convert(X)
}

pull_state_from_metro <- function(metro_name){
  str_extract(
    metro_name,
    ".*, (\\S{2})[-[:alpha:]]* Metro Area",
    group = 1
  )
}

metro_to_metro_migration <- function() {

  dest_file <- fs::path(data_mp03, "metro_to_metro_migration.json")

  if (!fs::dir_exists(data_mp03)) {
    fs::dir_create(data_mp03, recurse = TRUE)
  }

  # Only download if file does not exist
  if (!fs::file_exists(dest_file)) {
    message("Downloading metro-to-metro flows from Census API...")

    api_url <- paste0(
      "https://api.census.gov/data/2020/acs/flows",
      "?get=MOVEDIN,MOVEDOUT,FULL1_NAME,FULL2_NAME",
      "&for=metropolitan%20statistical%20area/",
      "micropolitan%20statistical%20area:*"
    )

    download.file(api_url, destfile = dest_file, mode = "wb")
    message("Download complete.")
  } else {
    message("Using cached metro flows file.")
  }

  # Read JSON file
  raw <- read_json(dest_file, simplifyVector = TRUE)

  # Convert to data frame and fix column names
  move_row_to_colnames(as.data.frame(raw)) |>
    # Simplify column names and drop unneeded columns
    select(
      metro1    = FULL1_NAME,
      metro2    = FULL2_NAME,
      moved_in  = MOVEDIN,
      moved_out = MOVEDOUT
    ) |>
    # Pull out primary state for each metro
    mutate(
      state1    = pull_state_from_metro(metro1),
      state2    = pull_state_from_metro(metro2),
      moved_in  = suppressWarnings(as.integer(moved_in)),
      moved_out = suppressWarnings(as.integer(moved_out))
    ) |>
    filter(!is.na(state1), !is.na(state2))
}

# lambda_ij = flow_ij / (pop_i * pop_j)
compute_lambdas <- function(flows_yr, pop_from_df,
                             pop_to_df, yr) {
  flows_yr |>
    filter(year_current == yr,
           state_current != state_1y,
           population > 0) |>
    left_join(
      pop_from_df |> rename(pop_i = population),
      by = c("state_1y" = "state_name")
    ) |>
    left_join(
      pop_to_df |> rename(pop_j = population),
      by = c("state_current" = "state_name")
    ) |>
    filter(!is.na(pop_i), !is.na(pop_j),
           pop_i > 0, pop_j > 0) |>
    mutate(
      lambda = population / (pop_i * pop_j)
    ) |>
    select(state_from = state_1y,
           state_to   = state_current,
           lambda)
}

# --- Step 3: Project one year forward ---
project_one_year <- function(pop_df, lambdas, gamma) {

  in_flows <- lambdas |>
    left_join(
      pop_df |> rename(pop_from = population),
      by = c("state_from" = "state_name")
    ) |>
    left_join(
      pop_df |> rename(pop_to = population),
      by = c("state_to" = "state_name")
    ) |>
    filter(!is.na(pop_from), !is.na(pop_to)) |>
    mutate(flow = lambda * pop_from * pop_to) |>
    group_by(state_to) |>
    summarize(total_in = sum(flow, na.rm = TRUE))

  out_flows <- lambdas |>
    left_join(
      pop_df |> rename(pop_from = population),
      by = c("state_from" = "state_name")
    ) |>
    left_join(
      pop_df |> rename(pop_to = population),
      by = c("state_to" = "state_name")
    ) |>
    filter(!is.na(pop_from), !is.na(pop_to)) |>
    mutate(flow = lambda * pop_from * pop_to) |>
    group_by(state_from) |>
    summarize(total_out = sum(flow, na.rm = TRUE))

  pop_df |>
    left_join(in_flows,
              by = c("state_name" = "state_to")) |>
    left_join(out_flows,
              by = c("state_name" = "state_from")) |>
    mutate(
      total_in   = coalesce(total_in,  0),
      total_out  = coalesce(total_out, 0),
      population = (1 + gamma) * population +
                   total_in - total_out
    ) |>
    select(state_name, population)
}

huntington_hill <- function(pop_df,
                             n_districts   = 435,
                             max_districts = 100) {
  pop_df |>
    expand_grid(cd = seq(0, max_districts)) |>
    mutate(
      hh_den    = sqrt(cd * (cd + 1)),
      hh_weight = if_else(cd == 0, Inf, population / hh_den)
    ) |>
    slice_max(hh_weight, n = n_districts) |>
    group_by(state_name) |>
    summarize(
      population  = first(population),
      n_districts = n()
    ) |>
    mutate(
      pop_per_district = population / n_districts
    ) |>
    arrange(desc(n_districts), desc(population))
}

#01: Expanding the House

The United States House of Representatives currently allocates 435 seats among 50 states using the Huntington-Hill method. While this system has remained unchanged since 1929, expanding the House beyond 435 seats would address two fundamental problems: unequal representation across states and California’s disproportionately weak voice in Congress.

Population Equity Across States

The core promise of the House is proportional representation — one person, one vote. In practice, the fixed size of 435 seats combined with the constitutional guarantee of one seat per state creates significant population imbalances. Based on our 2030 projections, California has approximately 688,274 residents per congressional seat, while smaller states enjoy far more representation per capita. Wyoming, for instance, receives a full seat for roughly 580,000 residents. This means a Wyoming voter has nearly 1.3 times the congressional representation of a California voter — a direct violation of the equal representation principle the House was designed to uphold. Expanding the House reduces this distortion because Huntington-Hill rounding errors — which systematically disadvantage large states — shrink as the total number of seats grows. With more seats to allocate, each state’s share of the House converges closer to its true share of the national population.

California’s Gain in a Larger House

One widely debated reform is the Wyoming Rule, which sets the size of the House so that the least-populated state (currently Wyoming) receives exactly one seat, and every other state receives seats proportional to that benchmark. Under this rule, the House would expand to approximately 585 seats based on current population. Running our Huntington-Hill model at this size:

The Broader Democratic Case

Beyond California’s interests, a larger House is simply better democracy. The United States currently has the worst representative-to-population ratio of any major democracy — roughly one representative per 760,000 residents. By comparison, Germany has one member of the Bundestag per ~120,000 residents and the United Kingdom has one MP per ~100,000 residents. The Founders themselves anticipated a growing House: the original Constitution specified one representative per 30,000 residents, which would imply a House of over 10,000 members today. A more modest expansion to 585 seats under the Wyoming Rule would meaningfully restore the representational link between citizens and their government, reduce the distortions created by Huntington-Hill rounding, and give California the political voice its 39 million residents deserve.
